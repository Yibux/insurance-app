- **Status:** proponowana | przyjęta | zastąpiona przez NNNN

- **Issue:** #<nr>
- **Wymagania:** FR-…, NFR-…

## Kontekst

Jaki problem rozwiązujemy, jakie są ograniczenia (licencje DE, limity scratch orgów, czas).

1. **Opcja A** — zalety / wady.
2. **Opcja B** — zalety / wady.

## Decyzja

Wybrana opcja i uzasadnienie (z odwołaniem do literatury, jeśli dotyczy).
